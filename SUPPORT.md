# Obtenir de l’aide

1. Consulte le README et la documentation du dépôt concerné.
2. Recherche dans les issues existantes pour voir si la question ou le problème a déjà été traité.
3. Pour un défaut reproductible, ouvre une issue avec les étapes, le résultat attendu et le résultat observé.
4. Pour une demande d’évolution, explique le besoin utilisateur et le résultat recherché.

Ne publie jamais de clé, mot de passe, donnée personnelle ou information confidentielle. Pour un problème de sécurité, suis la procédure de [SECURITY.md](SECURITY.md).
