# Code de conduite

Nous voulons des échanges respectueux, utiles et centrés sur le travail.

Sont attendus : la bienveillance, des critiques portant sur les idées et le code, l’écoute des différents points de vue et des retours formulés de façon constructive.

Ne sont pas acceptés : le harcèlement, les attaques personnelles, les propos discriminatoires, les menaces, la publication d’informations privées ou toute conduite qui empêche les autres de participer sereinement.

Les mainteneurs peuvent masquer un contenu ou limiter la participation lorsqu’un comportement enfreint ces règles. Pour signaler un problème, contacte les responsables de l’organisation par un canal privé sur GitHub.
