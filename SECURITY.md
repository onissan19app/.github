# Signaler une vulnérabilité

Merci de ne pas publier de vulnérabilité exploitable, de secret ou de donnée sensible dans une issue ou une pull request publique.

Utilise le signalement privé de vulnérabilité dans l’onglet **Security** du dépôt concerné, s’il est disponible. Sinon, contacte en privé un propriétaire de l’organisation sur GitHub en indiquant le dépôt concerné, les étapes de reproduction et l’impact observé.

N’effectue pas de test susceptible d’interrompre un service, d’altérer des données ou d’accéder aux données d’autrui. Nous accuserons réception et coordonnerons la suite du traitement avec la personne ayant signalé le problème.
